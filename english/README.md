# 十分钟英语 Daily English

给刚过四级的人每天 10 分钟读英语的小网站。纯静态（index.html + app.js + articles.json）。

每天三步：
1. **复习**到期单词（最多 12 个，间隔重复：1→2→4→7→14→30→60→120 天）。题型：看词选义、看义选词、例句填空、拼写、自评回忆。
2. **阅读**一篇约 250 词的短文（B2 / 六级水平）。荧光笔标出重点词；点任意单词查释义；每段可朗读、可显示中文。
3. **理解题** 3 道 + **今日新词**加入生词本（认识的可以跳过）。

文章来源：作为 claude.ai artifact 打开并登录时，每天由 Claude 按设置里的目标和兴趣新写一篇，并避开生词本里已有的词；否则使用 `articles.json` 里的 10 篇内置文章。

进度保存在浏览器 localStorage；在 claude.ai 上还会同步到 artifact 数据库（`profile/main`、`words/<id>`、`articles/<id>`）。学习记录页显示每天的阅读时长（只计有效时间）、正确率和打开时间。
