# 每日识字 Daily Hanzi

给小朋友每天 10 分钟认华文字的小网站。纯静态页面（index.html + app.js + data.js），不需要服务器。

- **每日任务**：先复习到期的字，再学几个新字（每个孩子可在「家长设置」里调整每天新字数量）。
- **间隔重复**：答对的字隔 1→2→4→7→14→30→60→120 天再出现；答错的字明天再来，并在当次练习中再考一遍。复习太多时自动减少新字。
- **题型**：看字选意思、听音选字、看意思+拼音选字、看字回忆（自评）。新字页面有读音、笔顺动画和描写练习。
- **我早就认识**：已经会的字一键放进字库，不浪费时间。
- **进度**：保存在浏览器 localStorage（每台设备各自保存）。换设备用「家长设置 → 下载备份 / 导入备份」。
- **字库**：`data.js` 里 336 个常用简体字，按主题分单元；可以直接增删，格式见文件开头注释。

发音用浏览器自带的中文语音（iPad / Mac / 大多数安卓和 Windows 都有）；笔顺用 Hanzi Writer（需要联网）。

笔顺数据 `strokes.json` 来自 [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data)（基于 Make Me a Hanzi，Arphic Public License），只截取了字库里用到的字。
